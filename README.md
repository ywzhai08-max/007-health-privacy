# Privacy Policy for 007 Health Agent

Last updated: October 7, 2026

007 Health Agent is a private personal health data analysis tool intended solely for personal use.

## Data Access

007 Health Agent may access health and fitness data authorized by the user through services such as WHOOP, including recovery, sleep, activity, workout, profile, and body measurement data.

## How Data Is Used

Health data is used solely to provide personal health analysis, trend monitoring, fitness insights, and assistance with personal health and fitness goals.

## Data Storage

Health data retrieved by 007 Health Agent is stored locally on the user's personal computer or in systems explicitly configured by the user.

## Data Sharing

007 Health Agent does not sell, rent, or share the user's health data with advertisers or unrelated third parties.

## User Control

The user may revoke access to connected services such as WHOOP at any time through the respective service.

## Contact

For privacy-related questions, please contact the application owner through this GitHub repository.
